# Твоя Каррера

Мобильный веб-прототип ежедневного тренера по LinkedIn. Откройте `index.html` в браузере или опубликуйте репозиторий через GitHub Pages.

## Возможности
- Начальная анкета
- 30 дней практических заданий
- Ссылки на LinkedIn
- Прогресс сохраняется локально в браузере
- Установка на главный экран через PWA

## Ограничения
Это демоверсия: нет облачной авторизации, настоящего ИИ и автоматического чтения LinkedIn. Кот временно обозначен эмодзи, оригинальный арт будет добавлен отдельно.

## Публикация
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.
